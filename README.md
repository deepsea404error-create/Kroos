# 寒芒克洛丝

以《明日方舟》中的寒芒克洛丝为原型制作的《杀戮尖塔》角色 Mod。

## 简介

寒芒克洛丝是一名以**寒芒**为核心资源的射手角色。消耗寒芒触发卡牌额外效果、积累专注触发暴击、利用浅眠与蓄势的节奏转换，构成了她的核心玩法。

## 安装

1. 安装 [ModTheSpire](https://github.com/kiooeht/ModTheSpire) 与 [BaseMod](https://github.com/daviscook477/BaseMod)
2. 将 `KroosMod.jar` 放入游戏的 `mods` 文件夹
3. 通过 ModTheSpire 启动游戏并勾选本 Mod

## 核心机制

| 机制 | 说明 |
| --- | --- |
| **寒芒** | 核心资源。大部分卡牌可消耗寒芒触发额外效果。 |
| **专注** | 当持有 ≥3 层时自动消耗 3 层，获得 1 层暴击。 |
| **暴击** | 攻击牌造成 1.5 倍伤害（持有瞄准镜时为 2.0 倍）。 |
| **破绽** | 敌人身上的标记，≥5 层时消耗 5 层施加"中的"。 |
| **中的** | 敌人行动前受到 10 点伤害，攻击行为转为眩晕。 |
| **迷彩** | 受到的攻击伤害降低 50%，每受击 1 次损失 1 层。 |
| **浅眠** | 非梦击牌伤害 ×80%；回合结束获得护甲并回复生命。 |
| **蓄势** | 退出浅眠时消耗：抽牌、回能、获得临时力量。 |

### 特殊牌类型

- **箭矢**：打出后自动获得其消耗能量数量的专注层数。
- **梦击**：在浅眠状态下不会降低伤害。
- **A1小队**：虚无、消耗类型的无色卡牌。

## 卡牌一览（共 79 张）

- **攻击牌** 26 张：初始 2（打击、二连射）、普通 10、罕见 9、稀有 5
- **技能牌** 30 张：初始 2（防御、预备射击）、普通 11、罕见 12、稀有 5
- **能力牌** 18 张：罕见 13、稀有 5
- **无色牌** 5 张：普通箭矢 + A1小队×4

## 遗物一览（共 14 个）

- **起始**：克洛丝证章
- **普通**：练习靶、残弩-典训
- **罕见**：瞄准镜、A1小组的合影、应急理智加强剂
- **稀有**：箭矢改良、应急理智浓缩液、分浪、基岩
- **BOSS**：成长的证明、源石、干员晋升证章、A1小队的支援
